## Key ideas

- **Supervised learning** — learn a mapping from features to a known label (classification or regression).
- **Unsupervised learning** — find structure in data without labels (e.g., clustering).
- **Training / validation / test sets** — fit on training data, tune on validation data, report final performance on held-out test data.
- **Loss function** — measures how wrong predictions are; training minimizes it.
- **Overfitting vs. underfitting** — too complex a model memorizes noise; too simple a model misses real patterns.
- **Evaluation metrics** — accuracy, precision, recall, F1, ROC AUC (classification); MAE, RMSE, R² (regression).
